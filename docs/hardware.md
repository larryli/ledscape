# 硬件设计文档

## 1. 系统概述

LEDScape 风筝 LED 灯效系统，基于 CH32V003 驱动 30 颗 WS2812B 灯珠，3.7V 锂电池直供电。

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  LiPo 3.7V  │───→│  主控板      │───→│  灯带 1米    │
│  400mAh     │    │  CH32V003   │    │  30×WS2812B │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 2.4 PCB 布局

```
              18mm
      ┌──────────────────────┐
      │ [JST-PH]  [MSK开关]  │  ← 上方：电池接口 + 开关
      │                      │
  12  │     [CH32V003]       │  ← 中央：MCU
mm    │      [100nF]         │
      │  ○            ○      │  ← 调试通孔对称
      │                      │
      │    ○  ○  ○ (灯带)    │  ← 下方：灯带通孔焊接
      └──────────────────────┘
            ↑ 灯带引线朝下
```

**布局说明：**
- **上方**：JST-PH 母座（左）+ 拨动开关（右），电池和开关同侧便于操作
- **中央**：CH32V003 居中，100nF 去耦电容紧贴 VDD/VSS
- **两侧**：调试通孔对称分布
- **下方**：灯带 3 个通孔（VCC/GND/DIN），引线朝下连接灯带

**优势：**
- 电池从上方接入，灯带从下方引出，走线分离
- 开关和电池接口同侧，单手操作方便
- 灯带通孔焊接更牢固，抗振动
- 整体上下对称，重心平衡

### 2.5 调试接口

2 个通孔，位于 PCB 上方，用于 SWIO 烧录调试：

| 通孔 | 功能 | 连接 |
|------|------|------|
| H1 | SWIO | PD1 |
| H2 | GND | VSS |

**灯带接口：**

3 个通孔，位于 PCB 下方，用于焊接灯带引线：

| 通孔 | 功能 | 连接 |
|------|------|------|
| L1 | VCC | 3.7V (经开关) |
| L2 | GND | VSS |
| L3 | DIN | PC6 |

## 3. 灯带

### 3.1 规格

| 参数 | 值 |
|------|-----|
| 型号 | WS2812B |
| 数量 | 30 颗 |
| 长度 | 1 米 (每颗间距 33mm) |
| 供电电压 | 3.7V (直供) |
| 数据速率 | 800kHz |
| 最大电流 | 1800mA (全白) |
| 典型电流 | 400-600mA (彩虹效果) |

### 3.2 接线

灯带引出 3 根线，通过通孔焊接到主控板：

| 灯带线 | 颜色 | 连接 | 焊接方式 |
|--------|------|------|----------|
| VCC | 红 | 主控板 L1 (通孔) | 穿孔焊接 |
| GND | 黑 | 主控板 L2 (通孔) | 穿孔焊接 |
| DIN | 白/绿 | 主控板 L3 (通孔) | 穿孔焊接 |

**通孔焊接优势：**
- 机械强度高，抗振动
- 焊接面积大，接触可靠
- 适合风筝飞行环境

### 3.3 安装方式

- 灯带沿风筝横梁骨架布置
- 用透明热缩管包裹防水
- 扎带固定在骨架上，间距 10cm

## 4. 电池

### 4.1 规格

| 参数 | 值 |
|------|-----|
| 类型 | LiPo 软包 |
| 型号 | 601010 |
| 容量 | 400mAh |
| 电压 | 3.7V (3.0V~4.2V) |
| 重量 | ~9g |
| 接口 | JST-PH 2.0mm 2pin |

### 4.2 续航估算

| 效果类型 | 典型电流 | 续航 |
|----------|----------|------|
| 彩虹流水 | ~600mA | 40 分钟 |
| 呼吸/烛光 | ~300mA | 80 分钟 |
| 混合播放 | ~450mA | 53 分钟 |

### 4.3 供电方式

```
电池 JST-PH 公头 ──→ 主控板 JST-PH 母座
                         │
                     拨动开关
                         │
                    CH32V003 + 灯带
```

3.7V 直供，无需稳压器。

## 6. 防护设计

| 措施 | 方法 |
|------|------|
| 防水 | 灯带套热缩管，焊点涂硅胶 |
| 防风 | 所有连接用热熔胶加固 |
| 防震 | 电池用泡棉包裹 |
| 防脱落 | 灯带用扎带绑在骨架上 |

## 7. 风筝安装

### 7.1 布置方式

```
风筝骨架
├──────────────────────────────────┤
│ ◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉◉ │  ← 灯带沿横梁布置
│          ↑                      │
│       主控板+电池               │
│       (中心位置)                │
└──────────────────────────────────┘
```

### 7.2 安装要点

- 灯带沿风筝横梁骨架布置
- 主控板和电池固定在风筝中心（保持平衡）
- 线材沿骨架走线，用扎带固定
- 所有接口涂硅胶防水

## 8. 飞行建议

- 风力：2-3 级微风
- 场地：开阔地，远离电线
- 首次试飞：地面测试平衡性
- 电池固定牢靠，防止脱落
